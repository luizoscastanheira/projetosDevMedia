# O projeto
Este projeto é um projeto simples, de **caráter didático e acadêmico** com intuito de demonstrar os conhecimentos básicos da Linguagem Java mostrando a base de qualquer aplicação.

# Objetivo
Criar uma aplicação de linha de comando que possibilite registrar qualquer tipo de itens colecionáveis ( ou não ;-) ), desde tampinha de garrafa a fitas cassete ou sei lá, seus jogos.

# O ambiente
A versão do Java vem da OpenJDK 25, em um ambiente de desenvolvimento Linux no S.O. ChromeOS Flex (sim é meu setup!!!), e claro, usando VSCode como IDE, com as devidas extensões oficiais instaladas.
